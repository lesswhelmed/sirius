## Cross-cutting conventions every plan assumes (verified during recon)

- Package manager: **bun 1.3.14**, turbo monorepo. `bun run db:generate` must run
  before `bun run check-types` (the Prisma client is gitignored).
- Verification gates: `bun run check-types`, `bun run lint`, `bun run test`;
  per-package `bun --cwd <pkg> test`; DB-integration suites via
  `bun run db:test:setup` then `bun --cwd packages/db test --preload ./test/setup-env.ts <file>`.
- **Shared-tree swarm rule**: this repo runs a multi-agent swarm on one working tree.
  Every plan says commit with explicit paths (`git commit -- <paths>`) and **never
  `git add -A`** (a bare add sweeps coworkers' staged files). Do not push or open PRs
  unless the operator says so.
- Commit style: conventional commits (see `git log`: `feat(mobile):`, `fix(worker):`,
  `chore(deps):`, `test(db):`, …).
